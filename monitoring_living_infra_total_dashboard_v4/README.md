# 생활인프라 편리성 모니터링 대시보드 v4 (시계열 비교)

v3 기반. **두 연도(이전 vs 최신)를 모든 탭에서 나란히 비교**하는 구조로 전면 재편.

## 빌드

```bash
python build.py     # → dashboard.html (단일 파일, 브라우저에서 바로 열기)
```

입력: `../생활인프라_시계열데이터/{연도}/output_test/` 의
composite / supply / service_pop / access index shapefile.
연도 폴더 추가 시 재빌드만으로 반영 — 비교쌍은 항상 (가장 이른 연도, 가장 최근 연도).

## 구조 (v3 대비)

- 헤더: `2023 vs 2024` 연도쌍 배지 (연도 셀렉터 없음 — 항상 두 연도 병렬)
- **요약**: 최고·최저·최대상승·최대하락 KPI, 부문카드·TOP10 전부 두 연도 값+Δ+순위변화 병기
- **지도**: 좌(이전) | 우(최신) 듀얼 맵 — 줌·이동·지표·클릭 동기화, 색상 등급은
  두 연도 통합 분포 기준 공통 척도. 하단 시트에 연도쌍 값·Δ·순위변화.
  500m 격자는 최신연도 지도에만 (시계열 아님)
- **지역별 상세**: 레이더(2023 점선 vs 2024 실선 + 시도평균), 공급·향유·충족 연한/진한 연도쌍 막대,
  상세표 Δ·순위변화, 연도별 추이 차트
- **지역별 비교**: 직접선택(≤2곳)은 연도 오버레이, 유사 5곳 모드는 최신연도 차트 + 표에 연도쌍
- **분포 분석**: 히스토그램 연도 겹침, 시도 박스플롯 연도쌍, 산점도 연도 2계열(회귀선 최신 기준)
- **변화분석**: ΔT점수 diverging 지도 + 순위변화 상승/하락 TOP 10 (지표·기간 선택)
- AI 챗봇: 도구 `year` 파라미터 + `compare_years` 도구, 연도쌍 비교 컨텍스트 인지

## 해석 주의

모든 지수는 **연도별 T점수(상대 표준화)**. 연도 간 점수 차이는 절대 수준 변화가
아니라 **전국 내 상대적 위치 변화**를 뜻한다. 모든 Δ에 순위 변화를 병기하는 이유.
