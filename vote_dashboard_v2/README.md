# 투표 결과 검증 대시보드 v2

제9회 전국동시지방선거(2026-06-03) 개표단위별 결과를 탐색하는 **브라우저 단독 정적 페이지**입니다. 빌드 도구·외부 라이브러리·서버 로직 없이 HTML/CSS/JS 3개 파일로 동작합니다.

## 구성

| 파일 | 내용 |
|---|---|
| `vote_dashboard_v2.html` | 화면 구조 |
| `vote_dashboard_v2.css` | 스타일 |
| `vote_dashboard_v2.js` | CSV 파싱·분석·렌더링 전체 로직 |
| `nec_0020260603_local_vccp08_long.csv.gz` | 중앙선관위 개표 원본(롱 포맷)을 gzip 압축한 데이터(약 3.7MB) |

## 데이터

- 원본은 **후보별 1행(long format)** CSV이며, JS가 선거·행정구역·개표상황표 키로 묶어 **개표단위 단위 레코드**로 변환합니다.
- 기본 로드는 `.csv.gz`를 `fetch` 후 브라우저 내장 `DecompressionStream("gzip")`으로 해제합니다. 압축본이 없으면 원본 `.csv`로 폴백합니다.
- 필수 컬럼 25개(`election_code`, `city_code`, `town_code`, `sgg_*_code`, `statement_id`, `읍면동명`, `투표구명`, `선거인수`, `투표수`, `후보순번`, `정당명`, `후보자명`, `득표수`, `후보자별 득표수_계`, `무효 투표수`, `기권자수` 등)가 없으면 로드를 중단합니다.

## 분석 기능 (버튼 4개)

1. **동일 투표수 지역 추출** — 같은 선거구·같은 투표구분·같은 1·2후보에서 **두 후보 득표수가 동일**한 개표단위가 2곳 이상이면 묶습니다.
2. **동일 비율 지역 추출** — 위와 같되, 유효표 대비 득표율이 **소수점 3자리까지 동일**한 묶음을 찾습니다.
3. **벤포드 법칙 점검** — 득표수 첫자리 분포를 벤포드 기대분포와 비교해 카이제곱을 계산합니다. 임계값은 χ² 15.51(주의)·20.09(검토 필요). **선거유형이 "전체"면 유형별로 분리 계산**하고, 특정 유형 선택 시 전체 후보·1후보·2후보로 나눠 봅니다.
4. **지역별 사전투표율** — `사전투표수 ÷ 최종 선거인수`를 도단위/시단위로 집계합니다. 사전투표수 = 관내사전투표 + 관외사전투표 + 거소투표. "전체"일 때는 중복을 피해 시·도지사선거 기준으로 계산합니다.

## 핵심 정의

**선거구(contestKey)** — 같은 후보가 경쟁하는 단위를 선거유형에 맞춰 정의합니다.

| 선거유형 | 선거구 단위 |
|---|---|
| 시·도지사·교육감·광역의원비례대표 | 시·도 전체 |
| 구·시·군의 장·기초의원비례대표 | 시·군·구 |
| 시·도의원·구시군의원·국회의원(지역구) | 선거구코드(sgg) |

**투표구분(voteCategory)** — `읍면동명`이 `합계`면 최종결과, `관외사전투표`·`거소투표`·`관내사전투표`면 사전투표, 그 외는 본투표.

**기본 제외 항목** — `잘못 투입·구분된 투표지`, `계`, `선거일투표`. 토글 버튼으로 포함해 다시 계산할 수 있습니다.

## 필터

선거유형 · 투표구분 · 사전투표율 단위(도/시) · 최소 투표수 · 기본 제외 항목 토글.

## 실행 방법

`fetch`와 `DecompressionStream`을 쓰므로 **로컬 웹서버에서 열어야** 합니다.

```bash
python -m http.server 8000
# http://localhost:8000/vote_dashboard_v2.html
```

`file://`로 직접 열면 기본 데이터 자동 로드가 막힙니다(상단 "CSV 선택"으로 수동 로드는 가능). 압축 해제를 지원하는 최신 브라우저가 필요합니다.

URL 파라미터로 분석을 바로 실행할 수 있습니다: `?run=sameVotes|sameRatio|benford|earlyTurnout`, `?includeExcluded=1`.

## 해석 주의

같은 선거구 안에서 같은 숫자·비율을 찾는 **탐색 도구**입니다. 동일값이나 벤포드 편차는 추가 확인 신호일 수 있으나, 그 자체로 이상이나 부정을 판정하지 않습니다. 선거 데이터는 행정구역 규모와 후보 수의 영향을 받습니다.
